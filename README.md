# AI 爆款文案 - Chrome 扩展

一键生成小红书爆款文案、抖音脚本、SEO文章、朋友圈营销文案。

## 功能

- 📕 **小红书文案** - 标题+正文+标签+emoji排版
- 🎬 **抖音脚本** - 口播脚本+分镜+引导互动
- 🔍 **SEO文章** - 标题优化+关键词+元描述
- 💬 **朋友圈文案** - 营销文案+配图建议
- 📝 **智能总结** - 核心观点+关键数据
- 🌐 **多语言翻译**
- ✏️ **专业润色**
- 🛒 **跨境电商Listing**

## 上架 Chrome Web Store 赚钱步骤

### 第1步：注册开发者账号
1. 打开 https://chrome.google.com/webstore/devconsole
2. 用你的 Google 账号登录
3. 支付一次性 $5 注册费
4. 完成开发者注册

### 第2步：打包上传
```bash
# 打包扩展
# 在 Chrome 浏览器中打开 chrome://extensions
# 开启"开发者模式"
# 点击"打包扩展程序"
# 选择本目录
# 或者直接压缩：
# 将整个文件夹压缩为 zip，上传到开发者控制台
```

### 第3步：配置定价
在开发者控制台：
1. 上传打包好的 `.zip` 文件
2. 填写商店信息（名称、描述、截图）
3. 设置定价：免费使用 + 应用内购买（或直接设为付费 $4.99）
4. 提交审核

### 第4步：设置 LemonSqueezy 收款（推荐）
1. 注册 https://lemonsqueezy.com
2. 创建产品 "AI 爆款文案 Pro"
3. 定价 $9.99/月 或 $99/年
4. 将许可证验证链接替换到 popup.js 和 options.js 中的 `your-lemonsqueezy-store.com`

### 第5步：推广
- 发到小红书：搜"AI工具推荐""文案神器"
- 发到抖音：展示一键生成效果
- 发到知乎：写"我开发了一个AI文案神器"
- 发到 ProductHunt
